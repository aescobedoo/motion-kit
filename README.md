# Motion Kit

Convierte una idea escrita en una animación lista para usar. No necesitas abrir la Terminal ni
editar código.

## Instalar una vez

1. Abre Codex o Claude Code.
2. Copia completo el [prompt de instalación](INSTALL-PROMPT.md) y pégalo en el chat.
3. Acepta los permisos que solicite tu computadora.
4. Responde las preguntas sobre tu estilo.
5. Cuando termine, cierra y vuelve a abrir Codex o Claude Code.

## Crear una animación

En **Codex**, escribe `$motion`. En **Claude Code**, escribe `/motion`.

Después pide el resultado con tus palabras:

```text
Crea una animación de pantalla completa que muestre cómo varias opciones se reducen hasta dejar
una sola decisión clara. Que dure cinco segundos y quede lista para mi editor de video.
```

Motion usa pantalla completa por defecto. También puedes pedir un **overlay transparente** o un
archivo **4:5 para Instagram o Canva**.

## Hacer ajustes

Di únicamente qué quieres cambiar:

- “Hazla más lenta.”
- “Usa menos brillo.”
- “Deja libre la parte inferior para subtítulos.”
- “Conserva todo, pero cambia el color azul por verde.”

Motion conservará lo demás y reemplazará el archivo.

## Si algo falla

Pega el error o una captura y escribe:

```text
Corrige el problema, comprueba la instalación y entrégame nuevamente el archivo final.
```
